# Kingsman: Secret Service Archive

## Project Reflection

**What’s something new you learned while building your site?**
I learned how to integrate JavaScript with CSS to create interactive elements. Specifically, learning how to build a toggling popup model, and how to utilize the HTML5 Canvas to create a continuous animation loop. These concepts were completely new to me, and it was fun to learn them!

**How did you balance creativity with usability?**
I wanted the site to feel like a classified, intelligence archive. This meant using a dark, and sleek color palette. Mostly Gold, White, and Black. To help ensure usability and readability, I used Bootstrap's grid system and navbar to keep the navigation as familiar as possible, and ideally predictable for the user. I also ensured that the interactive elements I used, like the pulsing "Sign Up" button and the parallax scroll (up and down), added visual intrigue without causing visual clutter. 

**What are you most proud of in your final project?**
I am most proud of how GOOD the interactive elements feel. Combining the Bootstrap framework with the custom JavaScript features (like the Canvas animation and the parallax scrolling) made the site feel polished and alive rather than just a static collection of web pages.

**How do you see yourself using these skills later on?**
Understanding the relationship between HTML structure, CSS design, and JavaScript helps give me a strong foundation for building digital portfolios, and or websites. The version control skills of using GitHub and framework experience with Bootstrap, are also heavily used in the industry, and will help greatly with future endevours.
